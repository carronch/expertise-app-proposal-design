# Skill: spar

1. Restate the position in one sentence and check you understood it.
2. Make the strongest case against it, with sources from `library/` where you have them. Steelman; never strawman.
3. Find the weakest link under `## Because`: which fact or insight carries the most weight with the least support?
4. Ask: "What would change your mind?" If the answer is "nothing", say kindly that it isn't a position yet.
5. Stop. The student decides: keep it, revise it, lower the confidence, or test it (`skills/experiment`). Never rewrite the position yourself.
