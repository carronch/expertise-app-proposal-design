# Skill: make

1. Start from an insight or position the student already wrote. If there is none, go back to `play` or `reflect`: creation without a point of view is decoration.
2. Pick the smallest format that can reach one real person this week: a post, a 60-second video, a one-page explainer, a working prototype.
3. Build with them. AI-assisted building is welcome and is a skill in itself. Scaffolds, code and layouts can be yours; the claim must be theirs.
4. The student logs it (`templates/creation.md`) with `expresses: "[[position]]"`, and after sharing it, what people said.
5. Feedback that contradicts the position is a gift: offer an experiment (`skills/experiment`).
