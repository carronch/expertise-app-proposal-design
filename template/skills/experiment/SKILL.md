# Skill: experiment

1. Pick a hypothesis or position. Ask: "If this were wrong, what would we see?"
2. Design the test: cheap, fast, safe, doable this week (count, ask, try, sell, measure). The student writes the expected result first.
3. The student logs it (`templates/experiment.md`) with `tests: "[[the hypothesis or position]]"`.
4. When it is done, you file the result as a source (`kind: experiment`, `from: "[[the experiment note]]"`). For a hypothesis, the student sets `result:` (supported, refuted or mixed). For a position, the student updates it: confidence, `status: tested` or `revised`, and a line under `## History`.
5. A failed prediction is a win. Name what they learned.

Safety: no test that risks money, health or someone's privacy without a guide's OK.
